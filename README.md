SpendWise – Smart Budget Tracker
Project Description

SpendWise is a simple and user-friendly personal finance management web application designed to help users manage their income, expenses, and monthly budgets.

The application allows users to record financial transactions, monitor their spending habits, calculate their remaining budget, and track their overall financial balance.

SpendWise uses browser Local Storage to save transactions and budget information, allowing users to retain their data even after refreshing the webpage.

The main goal of SpendWise is to encourage better financial management, responsible spending, and smarter saving habits.

Technologies Used

The project was developed using the following technologies:

HTML5: Used to create the structure of the application.
CSS3: Used to style the dashboard and make the application responsive.
JavaScript: Used to handle calculations, transactions, filtering, deleting records, and dashboard updates.
Local Storage: Used to save transactions and monthly budget information in the browser.
Git: Used for version control.
GitHub: Used to store and manage the project repository.
Netlify: Used to deploy and host the live website.

Deployment Process Summary

The SpendWise project was initially developed and tested locally using HTML, CSS, and JavaScript.

The project was then uploaded to a public GitHub repository using Git.

The GitHub repository was connected to Netlify to deploy the application online.

The following deployment steps were completed:

Organized the project files and checked the application locally.
Created a public GitHub repository named SpendWise.
Uploaded the project files to GitHub.
Connected the GitHub repository to Netlify.
Selected the main branch for deployment.
Configured the project for a static HTML, CSS, and JavaScript website.
Published the website using Netlify.
Changed the default Netlify site name to spendwise-finance-tracker.
Tested the live website to confirm that the application worked correctly.
Updated the JavaScript code to save transactions and budgets using Local Storage.
Pushed the updated files to GitHub.
Verified that Netlify automatically deployed changes from GitHub.
Challenges Encountered During Deployment

Several challenges were experienced during the deployment process:

Git Configuration: Initially, Git could not identify the user because the username and email were not configured.
GitHub Authentication: Authentication was required before uploading the project.
Git Push Errors: Some updates were rejected because the remote GitHub repository contained changes that were not available locally.
Merge Conflicts: Conflicts occurred in script.js and README.md while synchronizing local and remote files.
Data Persistence: Initially, transactions and monthly budgets disappeared after refreshing the webpage.
Netlify Deployment: It was necessary to understand how to connect GitHub to Netlify and verify successful deployments.

These challenges were resolved by configuring Git, authenticating with GitHub, resolving merge conflicts, implementing Local Storage, and testing the deployed application.
